MODEL DETAILS - Acacia EVs vs NVs on Ag/SiNWs (generated by Acacia_Paper_All.py)
==============================================================================
Software: Python 3.13.16, numpy 2.5.3, scikit-learn 1.9.1, matplotlib 3.11.2

DATA
  120 EV and 120 NV SERS spectra; 6 measurement sites per group, 20 spectra per site (sites = independent units).

PRE-PROCESSING (each spectrum, each window separately)
  1. cosmic-ray removal: modified z-score of first differences > 7; spike replaced by the mean of non-spike points within +/-3
  2. linear interpolation onto a 2 cm-1 grid: 205-1795 cm-1 (fingerprint), 2705-3095 cm-1 (CH)
  3. Savitzky-Golay smoothing: 11 points, polynomial order 3
  4. baseline: asymmetric least squares, lambda = 100000, p = 0.01, 10 iterations
  5. SNV within the window (mean 0, SD 1 per spectrum)
  analysis regions: 250-1790 cm-1 (770 points) and 2760-3095 cm-1 (168 points)

PCA
  5 components, exact SVD (svd_solver = "full"), mean-centred, labels not used. Figure 3 a/c: all 240 spectra. PCA-LDA classification: PCA fitted on the training folds only. PC1 sign: loading positive at 1580 / 2960 cm-1.

PCA-LDA
  LDA (scikit-learn LinearDiscriminantAnalysis, default SVD solver, equal-covariance) on PC1-PC5; priors = class proportions (0.5/0.5).
  Fig 3 b/d: LDA fitted on all spectra (display). Canonical variable 1 oriented NVs > 0.
  Statistics: Welch t-test on the 6 + 6 site means of canonical variable 1.

PLS-DA
  autoscaling (StandardScaler, fitted on training folds), PLS regression with 5 latent variables on y = 0 (EV) / 1 (NV), class NV if prediction > 0.5.

VALIDATION
  StratifiedGroupKFold: 5 folds, shuffle = True, random_state = 0, groups = measurement sites (a site is never in training and test at the same time).
    fold 1: test = EVs-m2, EVs-m6, NVs-m1 (60 spectra)
    fold 2: test = EVs-m1, NVs-m4, NVs-m6 (60 spectra)
    fold 3: test = EVs-m5, NVs-m3 (40 spectra)
    fold 4: test = EVs-m4, NVs-m5 (40 spectra)
    fold 5: test = EVs-m3, NVs-m2 (40 spectra)
  Comparison: PCA-LDA with PCA fitted once on all spectra.
  Permutation test: all 924 assignments of 6 of the 12 sites to "EV", full cross-validation repeated for each; p = labelings with accuracy >= real / 924.
  Sensitivity = NVs correctly classified; specificity = EVs correctly classified.

CH BAND FITTING (Figure S2, Table S6)
  mean spectrum of each group, 2780-3095 cm-1; straight baseline + 5 bands (start 2850, 2880, 2935, 2965, 3065 cm-1), position +/-12 cm-1, FWHM 12-60 cm-1, non-linear least squares (scipy least_squares);
  line shapes: Gaussian, Gaussian-Lorentzian sum (one mixing fraction per spectrum), Lorentzian.
    band II, EVs, Gaussian: 2886.9 cm-1, FWHM 60.0 (limit), 23.0 % of area, R2 0.9973
    band II, EVs, Gaussian-Lorentzian sum: 2880.8 cm-1, FWHM 60.0 (limit), 15.9 % of area, R2 0.9978
    band II, EVs, Lorentzian: 2875.2 cm-1, FWHM 60.0 (limit), 10.2 % of area, R2 0.9977
    band II, NVs, Gaussian: 2886.4 cm-1, FWHM 43.2, 22.5 % of area, R2 0.9997
    band II, NVs, Gaussian-Lorentzian sum: 2886.4 cm-1, FWHM 43.2, 22.5 % of area, R2 0.9997
    band II, NVs, Lorentzian: 2883.7 cm-1, FWHM 33.7, 10.0 % of area, R2 0.9983
